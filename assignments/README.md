# 作业（HW1—HW4）

四次作业占总评 30%，每次按 100 分评定、各占总评 7.5%。任务范围、分值与截止以本目录和各讲说明为准，**优先于历史讲义中的旧作业描述**。

## 统一评分维度

每项作业按四维评定：**正确性 40%、结果证据 30%、分析与局限 20%、复现与引用 10%**。四维用于打分，不与上表的任务百分比重复相加——任务百分比决定各小题的分值，四维决定每一小题内部怎么给分。

## 提交要求

- 交付可运行的 Notebook 或脚本 + 数据来源说明 + 运行步骤；关键结论须能由随附输出复算。
- 引用论文、数据库与 API 时给出 DOI/版本/访问日期；数据许可与单位必须写在报告开头。
- 使用 AI 辅助须声明任务、输入、输出与个人独立复核部分；不得把模型生成内容直接当作实验结论。
- 选做题用于拓展，不因具备 GPU 或付费服务而获得额外总评优势。
