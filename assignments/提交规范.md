# 提交规范（学生版）

本课程作业通过**钉钉课程群单聊**提交给教师。GitHub 仓库只用于分发资料，**不收作业**。

## 一、交到哪里

| 用途 | 渠道 |
|---|---|
| 作业正式提交 | **钉钉单聊发给何老师本人** |
| 课程公告、答疑、资料 | 钉钉群 |
| 群文件、群聊天 | **不要发作业**（全群可见，且容易被漏收） |

提交后教师**不会逐条回复**。每讲结束后群内会发布一次《收件核对表》（学号后四位 + 已收/未收/退回），请自行核对；有异议须在核对表发布后 48 小时内提出。

## 二、文件命名（必须严格执行）

```
HW1_20260001_张三.zip
HW2_20260015_李四.zip
论文评议_20260004_钱七.pdf
讨论记录_20260004_钱七.pdf
项目终稿_20260001_张三.zip
```

规则：`类型_学号_姓名.zip`，用下划线分隔，**不要空格、不要括号、不要"最终版""修改版"**。

命名不符的包会被退回，退回**不计为已提交**。原因很实际：教师靠文件名做批量归档和缺交统计，一个错名会让整批核对失效。

## 三、包里放什么

```
HW1_20260001_张三/
├── README.md      运行说明：环境、命令、预计耗时、预期输出
├── report.md      正文分析（数据许可与单位写在开头）
├── ai_usage.md    AI 使用声明
├── run.py         或 main.ipynb
├── src/           可选，多文件时用
├── data/
│   └── README.md  数据来源、许可、获取方式、SHA256
└── outputs/       真实运行产生的东西
    ├── run.log    必需
    └── fig_*.png / tbl_*.csv
```

直接从仓库 `assignments/提交模板/` 复制，改目录名为 `HW1_学号_姓名`，填内容，压缩。

**四条必须守住的**：

1. `outputs/` 必须是**真实跑出来的**，含 `run.log`。教师会重跑一次比对关键数字；与 `run.log` 对不上又解释不清的，该项按未完成处理。**不要截图当结果**，用 `savefig` 出图。
2. 数据超过 20 MB **不要塞进包**，在 `data/README.md` 写清来源、许可、获取命令和 SHA256。
3. **不要放 API 密钥、个人凭据、未授权的科研原始数据**。包内若检出密钥，该包判结构不合格，教师会通知你吊销后重发清理版；48 小时内未重发的按未提交处理。
4. `README.md` 写清预计运行时长。超过 10 分钟的，必须附上已冻结的 `outputs/`。

## 四、怎么打包

Windows：右键文件夹 → 发送到 → 压缩(zipped)文件夹。中文文件名不会有问题，教师侧脚本已做兼容。

macOS：右键 → 压缩。注意压缩包内会多出 `__MACOSX` 和 `.DS_Store`，不影响验收，可不管。

压缩后**检查一件事**：双击打开 zip，确认里面第一层就是 `HW1_学号_姓名/`，而不是再套一层同名目录、也不是散着一堆文件。

## 五、截止与迟交

- 截止时刻以**钉钉单聊消息的实际发送时间**为准，不看文件修改时间、不看压缩包内时间戳。
- 迟交、补交与学术不端的处理执行学校既有规定。

## 六、会被退回的六种情况

| 情况 | 处理 |
|---|---|
| 文件名不符 `类型_学号_姓名` | 退回，改名重发，退回期间不算提交 |
| 缺 `ai_usage.md` | 退回补交 |
| 缺 `outputs/run.log` | 退回补交 |
| `outputs/` 里只有 run.log，没有任何图或表 | 退回补交 |
| 包内检出疑似密钥 | 通知吊销后重发清理版 |
| 发到群文件或群里 | 视为未提交 |

## 七、学术诚信

- 可以讨论方法、互相看代码思路；**不要传阅成包提交物**，不要代跑代交。
- 用了 AI 必须在 `ai_usage.md` 写明任务、输入、输出和你的独立核验部分。未声明而实际使用的，按大纲既有条款处理。
- 引用他人代码（含课程示例、开源仓库）须在 `report.md` 标注来源与改动范围。
