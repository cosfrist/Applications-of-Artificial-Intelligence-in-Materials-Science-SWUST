# 资源与许可说明

> 本文件说明仓库内各类资料的权利状态、来源与使用边界。若与各文件内部的说明冲突，以本文件与根目录 `LICENSE` 为准；仍不明确的，请直接联系授课教师。

## 一、分层的权利状态

| 类别 | 位置 | 权利状态 | 可否再分发 |
|---|---|---|---|
| 代码 | 各讲 `code/`、`environment/` | MIT（见根目录 `LICENSE`） | 可以，保留版权声明 |
| 讲义、课件、课堂表单、作业 | `lectures/`、`assignments/` | 授课教师原创，仅限本课程教学使用 | **不可**，需书面许可 |
| 教材 PDF | `resources/教材-ISLP-Python版-2023.pdf` | 版权归作者与 Springer；作者官网免费发布 | 见第二节 |

| 论文 | 不在本仓库，仅 `resources/论文阅读清单.md` 给引用 | 版权归各出版方 | 只给 DOI / arXiv 链接 |
| 课程海报 | `resources/课程海报-A2-150dpi.png` | 授课教师原创 | 不可，需书面许可 |

## 二、教材为什么放、参考书为什么不放

**放 ISLP**：作者在 <https://www.statlearning.com> 长期免费提供全书 PDF，本仓库副本只是免去学生翻墙和注册的成本。若作者或出版社提出异议，本仓库立即撤下该文件，改为只留官方链接。

**不放两本参考书**：张统一《An Introduction to Materials Informatics》两册为 Springer 在售版权图书，**在公开仓库再分发属于侵权**，且 68 MB 级二进制一旦进入 git 历史便不可撤销。需要阅读的学生请通过学校图书馆或出版社获取；课堂用到的章节选段由授课教师另行给出阅读指引。

书目、ISBN 与 DOI 见 [`../resources/教材与参考书.md`](../resources/教材与参考书.md)。

## 三、论文只给引用

`resources/论文阅读清单.md` 只列题名、作者、年份、DOI 或 arXiv 编号，不存放第三方 PDF。原因：

1. 多数出版社许可不允许公开再分发；
2. 本仓库是公开仓库，任何上传都会被搜索引擎与爬虫长期缓存；
3. 学校图书馆已有订阅，学生通过正规渠道获取更可靠。

## 四、证据强度与"未核验"标注

课程资料强调可追溯。本仓库中：

- **已核**：教材与参考书的 ISBN/DOI（2026-10-28 逐条解析通过）；各讲课件与讲义的页数、SHA256 见各讲源目录的清单文件。
- **题名级/章节级**：`docs/逐讲教材章节与论文导航-V5.md` 与 `resources/论文阅读清单.md` 中的选段与论文定位，**页码与图号未逐条核验**，以各讲 `source_index-V5.md` 为准。
- **推断**：凡标注"待核""制作时核"的条目，均为制作阶段需复核项，不作为已确认事实使用。

## 五、学生数据与在线服务

- 学生自有科研数据**不得未经许可上传**到任何在线模型或公开仓库。
- 课堂与考核均提供离线数据替代路径；网络条件、GPU 与付费服务不影响评分。
- 课程 API（Materials Project、NOMAD 等）由学生自行申请，密钥不得提交到本仓库。若误提交，请立即吊销并告知教师。
