## 十例的证据层级

每例都标明该工作属于 **模型流程 / DFT 或模拟 / 实验 / 器件** 中的哪一层，并单列「结果」页交代结论止于何处。案例页配图由授课教师自行生成（非原文插图），图注中的原论文图号只用于溯源对照；完整引用、图号与图源记录见 `课程导论-来源与阅读说明-V5.md`。
