## 90 分钟怎么上

1. **0—35′**：独立《课程导论》49 页（P2 导航 1、教师 8、十例 12、资源 9、规则 5）。
2. **35—37′**：本讲 P1 封面 → P2 阅读导航 → P3 学习结果。
3. **37—55′**：问题链 18 分钟（P8—9 3、P17 3、P24 3、P40 3、P42 3、P43 1.5、P49 1.5）。
4. **55—70′**：数据与证据 15 分钟（P21—23 4、P25 3、P27—29 4、P51/P56 4）。
5. **70—85′**：P59 学生独立预检 15 分钟（读 3 / 换算 4 / 图 4 / 版本 4）。
6. **85—90′**：P60 退出题 4 分钟（写 2 + 互看 2）+ P58 收束 1 分钟。

主讲 21 页 + 任务 2 页（P59/P60）+ 支持 37 页 = 60 页；支持页不占额外分钟。

## 预检入口与边界

在包根执行（普通 `python`，Windows 默认 GBK 控制台可用）：

```bat
python "code/运行预检-V5.py" --out "学生运行/首次预检"
```

- 单步：`--step read` / `summary` / `figure` / `version`，**每步各用新目录**。
- 只允许包根下全新目录；拒绝已有目录、包根本身、`code/`、`课程导论/`、`assets/`、`学生分发-V5/`。
- 四步各自退出 0；`figure`/`all` 才核对新 SVG；`read/summary/version` 不要求 SVG。
- 冻结核心 `环境验收.py`、`带隙小样本.csv`、既有 SVG 三件字节不变；workflow 绑定入口自身 SHA/bytes。
- 预检不另加 2 分；正式过程任务卡 2 分在第 2 讲完整卡评价。
