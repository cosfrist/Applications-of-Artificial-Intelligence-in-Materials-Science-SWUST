# 01 材料信息学导论与 AI 产业

> 第 1 讲 · 2 学时 / 90 分钟 · 课件 60 页（必讲 23 页）
> 90 分钟 = 独立《课程导论》35 分钟 + 本讲 55 分钟

## 本讲目标

把「AI 用于材料」从口号拉回到可核查的证据链：看清数据驱动在四种研究范式中的位置，分清**候选、预测与实验验证**的证据层级，并在一页之内说清一个材料问题能不能被机器学习接住。
