## 一、环境准备

> **本课程统一环境名：`MICourse`**。后续 15 讲全部在此环境中扩展，不要为每讲单独建环境。

### 方案 A：Conda（推荐，本课程标准环境）

```bash

conda install -n MICourse jupyterlab ipykernel -y

# 5. 注册为 Jupyter 内核，使Notebook 能直接选到该环境
conda activate MICourse
python -m ipykernel install --user --name MICourse --display-name "Python (MICourse)"

# 6. 验证
conda run -n MICourse python -c "import numpy, pandas, sklearn, matplotlib; print('环境正常')"
```

> 本课程第 1—2 讲的全部任务与第 3 讲的清洗/建模核心都可用离线快照完成；

> 不申请 key 不影响任何评分项。

```bash
# 1. 注册并登录 https://materialsproject.org/
# 2. 进入 https://next-gen.materialsproject.org/api
# 3. 复制 API key
# 4. 写入本机环境变量（不要写进代码或提交到 git）
export MP_API_KEY=your_key_here       # macOS/Linux
setx MP_API_KEY your_key_here# Windows
```

代码中通过环境变量读取：

```python
import os
from mp_api.client import MPRester
mpr = MPRester(os.environ['MP_API_KEY'])   # 推荐
# 或者
mpr = MPRester()                             # MPRester 会自动读环境变量
```

> **学术诚信提醒**：API key 属于个人凭据，不要写入代码文件、不要发到群里、不要提交到版本库。第 1 讲已强调 AI 与凭据的使用边界，API key 同理。

### 脚本二：`示例2-材料发现范式与化学空间.py`

**对应旧版 PPT**：第 14、30、32–35、37 页

| 部分 | 内容 | 教学目的 |
|---|---|---|
| 一 | 手算化学空间规模 | 理解 10¹² 是怎么来的（公式有误，见下） |
| 二 | 四范式成本结构对比 | 定性说明试错为何赢不了 |
| 三 | 带隙 vs 电负性 | 说明单一特征解释力有限 |
| 四 | 三联可视化 | 汇总呈现 |

**输出**：`输出/lec01_paradigms.png`（三联图）

**脚本输出与已知缺陷（历史，本轮未重跑）**：

- ⚠️ **本脚本的计数公式有误，正确值见 PPT P16**：脚本把 `∏(N−i)/k` 当成组合数，实际不是 C(N,k)，
  于是得到 1.87×10¹⁸（高估约 3×10⁵ 倍）。正确口径为 **Σ_{k=1..10} C(89,k) ≈ 5.80×10¹²**。
  脚本与图按任务要求**冻结保留、未修改**，作「组合数公式易错」的教学反例；
  **课堂与作业不得引用 1.87×10¹⁸**，需要计数时以 P16 的口径说明（89 选 1—10、不计比例与结构）为准。
- 覆盖 1% 化学空间（10¹⁰ 候选）所需评估次数：经验试错 2×10¹¹ 次 → 理论计算 1.7×10⁸ 次 → 数据驱动 3.3×10⁵ 次。
  这些是按脚本参数推得的历史数字，本轮未复算，**不作当前结论**。
- 带隙与平均电负性 r = 0.482、R² 0.232 与 GaN/GaAs 对比同属旧输出，未核；仅用于引出第 4–5 讲的多维特征。

## 五、常见问题

**Q: `ModuleNotFoundError: No module named 'pymatgen'`**
这两个历史示例都不需要 pymatgen。若误装后报错，检查是否在错误的虚拟环境中。

**Q: 中文显示为方框**
脚本已设置 `plt.rcParams['font.sans-serif']` 为微软雅黑/黑体。若仍失败，说明系统缺少中文字体，可注释掉该行，不影响代码逻辑。

**Q: 图上出现方框（缺字）**
图表标签一律避免使用上标数字（如 10⁶）——微软雅黑不含上标字形，会渲染成方框。脚本已改用 `10^6` 形式，柱顶另标 `1e+06` 给出精确量级。

**Q: 报 `FigureCanvasAgg is non-interactive` 警告**
说明当前环境没有图形界面（如 Jupyter 无头模式、远程终端）。脚本已自动检测并跳过弹窗，图片照常保存到 `输出/`，不影响结果。

**Q: `LeaveOneOut` 跑得慢**
要训练 16 个随机森林。若机器较慢，可把 `n_estimators=30` 改为 `10`。本轮未在本机重跑，不给耗时承诺。

**Q: 每次运行的数字有微小差异**
脚本固定了 `random_state`；但不同库版本、不同机器仍可能有差异，本轮未重跑，不声称「多次完全一致」。
若你改了 `n_estimators` 或特征，数值当然会变——这正是「小样本评估对设定敏感」的演示。

## 六、代码自检

两个历史示例都在开头做了断言式自检，防止教学 bug 混进课堂：

- 脚本一的`parse_formula` 附带 6 组化学式解析用例（Si / CdTe / GaAs / SiC / TiO₂ / AlP）。这一段特别处理了子串匹配陷阱——`'S' in 'Si'` 为真、`'C' in 'CdTe'` 为真，若不做正则解析就会得出「Si 含硫」这类荒谬结果。

如自行验证这两个历史脚本，在 `MICourse` 环境下执行：

```bash
conda run -n MICourse python 示例1-材料数据的真实形态.py
conda run -n MICourse python 示例2-材料发现范式与化学空间.py
```

正常结束会打印 `✅ 运行完成` 与图表路径（示例 2 的计数仍是错的，见 §三）。
