# 第1讲课堂预检入口

本次15分钟预检仅用Python标准库。后续课程所需NumPy等按对应课次准备，不把本次预检当作全课程依赖验收。

在教师包或学生包根目录执行：

```bat
python "code/运行预检-V5.py" --out "学生运行/首次预检"
```

四个单步为`read`、`summary`、`figure`、`version`；各单步必须使用不同的新目录。`figure`/`all`核对新图，其他步骤不要求新图。已有目录、code、课程导论等受保护目录和包外路径均会拒绝；失败需保留真实报错，换新目录重试。

核心`环境验收/环境验收.py`、12行×5列教学CSV及既有SVG为冻结输入；由保护入口在新工作副本中调用。请勿把冻结核心当成可直接覆盖输出的课堂命令。当前包不要求安装额外软件、登录API或运行历史示例。`environment.yml`是另存的环境规范，不能当作本次实测版本锁。

数据仅为读取/单位换算教学样例：bandgap_J缺6行，6条双单位记录最大偏差约0.000638eV；不是NOMAD379条记录，不产生新材料科学结论。预检不另加2分，正式任务卡2分在第2讲评价。
