# 第 1 讲课堂实践：基础 Python 预检（15 分钟）

本目录只服务于第 1 讲第 59 页的**基础预检**，不是完整的课程环境安装包。

## 它验证什么

| 步骤 | 命令 | 观察点 |
|---|---|---|
| 1 读取 CSV | `python 环境验收.py --step read` | 12 行 × 5 列；`bandgap_J` 缺 6 行 |
| 2 核对单位换算 | `python 环境验收.py --step summary` | 同时含 eV 与 J 的 6 条记录，最大偏差 **0.000638041261062483 eV**（S05 MgO；脚本显示 0.0006 eV） |
| 3 保存结果图 | `python 环境验收.py --step figure` | 生成 `输出/lec1_env_check.svg`（带样本名、带隙刻度与说明） |
| 4 登记版本 | `python 环境验收.py --step version` | Python 版本、位数、平台 |

一次跑完：`python 环境验收.py`

## 它不验证什么

本页只证明「Python 能读文件、能算、能存图、能记版本」这条最小链路可用。
**不代表** numpy / pandas / scikit-learn / matplotlib / pymatgen 已安装或可用——这些课程依赖按
《MICourse 课前环境清单》另行验收，不要求在第 1 讲课堂内完成安装。

跑不起来时，报错用于**登记困难**；再通过离线数据、机房或替代环境补齐「读取→运行→保存图」三项，
才算完成本次预检。CPU 路径与离线路径同等计分。

## 依赖与运行要求

- 仅用 Python 标准库（`csv`、`os`、`platform`、`argparse`），无需安装任何包。
- 2026-10-24 在 Windows 11 + Python 3.14.5 上由制作端实跑通过（12 行 × 5 列、缺 6 行、最大偏差 0.000638041261062483 eV）；其他 Python 3.8+ 版本预期可用，但需自行登记实际输出。
- 结果图为 SVG，用浏览器（Edge/Chrome）双击打开即可；也可另存为 PDF。

## 文件说明
