# 第 2 讲 任务卡与数据源选择表（V5）

> **时间**：20 分钟完成任务卡五项并填选源表的“源意向”；随后 25 分钟数据块内沿同一张表补齐其余四列，不额外加时。
> 本表是第 3 讲 30 分钟来源/单位/重复审计的输入；样本 ID、结构/工艺/测量条件要分清，同式是否聚合按应用目标决定。
> 计过程证据 2 分，不新增长报告。
> 五项/五列缺项要写“待补”并说明理由；示例可用本方向材料，光电只是示范。

## 一、任务卡（一人一份，20 分钟）

| 项 | 你要写什么 | 我的填写 |
|---|---|---|
| 1 输入 X | 预测那一刻拿得到的变量；训练用但预测拿不到的必须剔除 | |
| 2 目标 y | 预测什么量、单位、由什么方式产生（算法/泛函/测试协议）；无监督探索写“无标签/探索” | |
| 3 样本单位 | 一行代表什么：材料/结构/器件/批次 | |
| 4 预测时可得信息 | 到“预测那一刻”为止的信息边界；写明时点（如工艺前） | |
| 5 验证标准 | 划分方式、指标、可接受误差、对照基线 | |

**任务类型**（回归/分类/排序/优化/无监督探索）：__________　**为什么不是另一种**：____________________

> 若选“无监督探索”：y 栏写“无标签/探索”，并另写一句独立领域检验（如聚类结果与相/结构的独立证据）。

## 二、数据源选择表（先填源意向，25 分钟块内补齐）

| 列 | 要写什么 | 仓库 1 | 仓库 2（可选） |
|---|---|---|---|
| 来源 | 仓库名、版本/查询日期、DOI 或稳定网址 | | |
| 目标字段含义 | 字段名、物理含义、是否二次加工量 | | |
| 单位 / 方法 | 单位、泛函/测试协议、温度与条件 | | |
| 许可 | 许可类型、是否需注册/订阅、引用要求 | | |
| 访问 / 离线方式 | API/批量/网页；离线能否复现 | | |

## 三、自查（提交前）

- [ ] 五项没有把“预测时拿不到的信息”写进 X
- [ ] 监督目标写单位与产生方式；无监督写无标签/探索及独立领域检验
- [ ] 样本单位不是“一条数据”
- [ ] 选源表写了许可与查询日期
- [ ] 未把“未收录”当成“不存在/不行”
- [ ] 若为无监督探索，已写独立领域检验
